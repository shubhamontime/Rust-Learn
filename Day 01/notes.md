# Rust File Extension

* Rust source code files use the **`.rs`** extension.
* Example: `main.rs`

# Print Hello World in Rust

**File name:** `main.rs`

```rust
fn main() {
    println!("Hello world!");
}
```

### Compile the code

<u>Command:</u>

```bash
rustc main.rs
```

### Run the code

<u>Command:</u>

```bash
./main
```

**Flow:** Write code → Compile → Run
